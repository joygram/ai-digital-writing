# 오픈소스로 만드는 AI 디지털 글쓰기

이 페이지는 AI 디지털 글쓰기 강의의 공개 프레젠테이션 진입점이다.

강의는 AI가 문장을 대신 쓰는 것을 넘어, 조직 문서를 만들 때 필요한 조건, 근거, 검증, 출력 흐름을 DocuMeta와 RAG 중심으로 설명한다.

## 보기

- [프레젠테이션 원고](presentation.md)
- [강의 시간표](timetable.md)

## 다루는 내용

1. 업무 문서를 이루는 대상, 형식, 근거, 출력 조건
2. DocuMeta로 문서 슬롯과 검증 규칙을 고정하는 방법
3. RAG로 근거 문서를 연결하고 출처를 남기는 방법
4. Quarto, Typst, HWPX로 최종 산출물을 만드는 흐름
