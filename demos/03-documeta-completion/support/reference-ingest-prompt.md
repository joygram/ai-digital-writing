# Reference ingest prompt

아래 규칙은 사람이 미리 정의한 시연용 ingest 지시다.
LLM이 근거자료를 자유롭게 고르는 것이 아니라, 이 규칙을 기준으로 샘플 원문을 검색 가능한 reference chunk로 분리한다.

## 목표

- 샘플 원문에서 슬롯을 채울 업무 근거를 분리한다.
- 각 reference chunk에는 원천 위치, 작성 주체, 사용 목적, 대상 슬롯을 남긴다.
- 현재 공문과 무관한 문서도 하나 포함해서 retriever가 제외할 수 있는 반례를 둔다.

## 분리 규칙

| 생성 파일 | 원문 기준 | 작성 주체 | 사용 목적 | 대상 슬롯 |
| --- | --- | --- | --- | --- |
| `work-plan.md` | `- 일시:` | 정보화지원팀 운영 담당자 | 점검 일정 근거 | `schedule` |
| `impact.md` | `- 대상과 영향 범위:` | 정보화지원팀 서비스 담당자 | 영향 범위 근거 | `scope` |
| `previous.md` | `- 사전 조치:`, `- 문의:` | 총무팀 공문 담당자 | 사전 조치와 문의처 근거 | `required_actions`, `contact` |
| `mail.md` | `- 메일 서비스 개편은` | 정보화지원팀 서비스 담당자 | 현재 공문과 무관한 문서 반례 | 없음 |

## 출력 규칙

- 각 chunk는 Markdown 문서로 저장한다.
- 문서 첫머리에 `RAG 세트 생성: 시연 3 ingest step`을 둔다.
- `원천`, `업무상 작성 주체`, `사용 목적`, `대상 슬롯`을 명시한다.
- 마지막에는 실제 근거 문장을 라벨과 함께 둔다.
- 원문에 없는 내용을 추론해서 추가하지 않는다.
